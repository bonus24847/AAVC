เป้าหมายวันนี้: ได้ไฟล์ captures/survey_track.jsonl ที่มี 5 จุดยืนนิ่ง — NW, NE, SE, SW และจุด L&R — เพื่อเอาไปทำพิกัดแมพชุดใหม่ วิธีเดียว: เสียบสาย USB โน้ตบุ๊ก ↔ Pixhawk แล้วอุ้มเดินไปด้วยกัน

ติ๊กแล้ว 0/0
วันนี้ไม่ต้อง arm ไม่ต้องบิน — แค่เปิดเครื่องแล้วอุ้มเดิน (ถอดใบพัดได้ยิ่งดี) · ทุกจุดต้องเก็บใน รอบเดียว วันเดียว — ข้ามวันแล้ว bias ของ GPS จะไม่หักล้างกัน
A

เช็กสาย + logger ก่อนออกจากบ้าน ที่โต๊ะ · เปิดโดรนเสียบสายไว้ 

cd ~/Desktop/"mission AAVC in kmutnb"

# A1 เสียบสาย USB จากโน้ตบุ๊กเข้า Pixhawk แล้วดูว่าโผล่พอร์ตไหน
ls /dev/ttyACM* /dev/ttyUSB* 2>/dev/null

# A2 ลองรันจริง 30 วิ แล้วกด Ctrl-C (ไฟล์ทดสอบ ไม่ใช่ของจริง)
env -u PYTHONPATH .venv/bin/python tools/survey_logger.py \
    --url /dev/ttyACM0 --baud 921600 --out /tmp/survey_test.jsonl
ต้องเห็น [survey] linked (sys 1). Recording → /tmp/survey_test.jsonl แล้วตามด้วยบรรทัดสดที่นับจุดขึ้นเรื่อย ๆ · เจอพอร์ตไหนให้เลือกในแถบด้านบน คำสั่งข้างล่างจะเปลี่ยนตาม
ปิด QGC / AAVC GCS / mavlink-router ให้หมดก่อน — โปรแกรมพวกนี้จับพอร์ต serial ไว้ logger จะขึ้น no heartbeat ทั้งที่สายเสียบอยู่ดี ๆ
ตั้งโน้ตบุ๊กไม่ให้หลับตอนปิดฝา — วันเดินต้องอุ้มโน้ตบุ๊กไปด้วยและ logger ต้องรันตลอด ถ้าเครื่อง suspend การบันทึกจะขาดกลางคัน (จะเดินแบบเปิดฝาค้างไว้ก็ได้)
B

เริ่มบันทึกจริง ยืนที่จุด L&R ก่อนออกเดิน

เปิดโดรน รอ GPS ขึ้น 3D fix ดาวเทียม ≥ 10 ดวงก่อน แล้วค่อยสั่ง

cd ~/Desktop/"mission AAVC in kmutnb"
env -u PYTHONPATH .venv/bin/python tools/survey_logger.py \
    --url /dev/ttyACM0 --baud 921600 --out captures/survey_track.jsonl
บรรทัดสดที่ต้องเห็น [survey] 1234 จุด | 3D sats 14 | 13.8224940, 100.5122771 นิ่งมา 42s

ขึ้น ⚠ สัญญาณอ่อน = fix ต่ำกว่า 3D หรือดาวน้อยกว่า 8 → รอ อย่าเพิ่งเดิน

C

เดินเก็บมุม — ไม่ต้องพิมพ์อะไรเลย กลางสนาม · ~10 นาที

อุ้มโดรน + โน้ตบุ๊กไปด้วยกัน (สายห้ามหลุด) เดินตามเข็มนาฬิกาเริ่มมุมบนซ้าย แล้วจบที่จุดขึ้น-ลงจริง ยืนนิ่งจุดละ ≥ 30 วินาที — หน้าจอนับ “นิ่งมา …s” ให้เห็น

  • ยืนที่ ขอบที่ยอมให้โดรนบินถึง (ขอบนอกลู่วิ่ง) ไม่ใช่ขอบหญ้า — ค่านี้จะกลายเป็น geofence
  • อย่าเดินตัดมุม ระหว่างเดินระบบทิ้งอัตโนมัติ นับเฉพาะช่วงที่ยืนนิ่ง
  • นิ่ง = ขยับน้อยกว่า 0.8 m · ยืนไม่ถึง 20 วิ = จุดนั้นหายไปเลย ยืนเผื่อเป็น 45 วิปลอดภัยกว่า
  • ถือโดรนสูงระดับเดิมทุกจุด อย่าเอาตัวเองบังท้องฟ้าฝั่งเสา GPS
  • ถ้าสายหลุด/เครื่องหลับกลางทาง: กด Ctrl-C ทิ้ง แล้วเริ่มใหม่ทั้งรอบ — ครึ่งรอบใช้ไม่ได้
D

ปิดงานแล้วเช็กว่ามีข้อมูลจริง ยืนอยู่จุดสุดท้ายนั่นแหละ 

# D1 กด Ctrl-C ในหน้าต่างที่รัน logger

# D2 ควรได้หลายพันบรรทัด
wc -l captures/survey_track.jsonl
ต้องเห็นตอนกด Ctrl-C [survey] wrote <N> samples → captures/survey_track.jsonl
E

แปลงเป็นพิกัด — ทำตรงนั้นเลย ก่อนเก็บโดรน ยังอยู่ในสนาม 

env -u PYTHONPATH .venv/bin/python tools/survey_extract.py \
    captures/survey_track.jsonl --names "NW,NE,SE,SW,LR"

ตรวจ 3 อย่างนี้ก่อนเก็บของ — ไม่ผ่านก็ยังยืนอยู่ในสนาม เดินซ้ำได้ทันที

ถ้าต้องเดินซ้ำ ให้เริ่ม logger ใหม่โดยเปลี่ยนชื่อไฟล์ --out captures/survey_track_2.jsonl — ใช้ชื่อเดิมมันจะเขียนทับของที่เพิ่งเดินมา
F

แก้แมพจริง กลับถึงบ้าน 

# F1 วางค่าที่ extract พิมพ์ออกมา (FIELD_CENTER_LAT/LON, AXIS_DEG,
#    AIRSPACE_S/T, LNR_ST) ลงหัวไฟล์ tools/gen_geo.py แล้วสั่ง
env -u PYTHONPATH .venv/bin/python tools/gen_geo.py

# F2 ก๊อป output ไปวางให้ครบทั้ง invariant (gen_geo ไม่เขียนไฟล์เอง โดยตั้งใจ)

# F3 ภาพพื้นสนามใหม่ตามกรอบใหม่ — ต่อเน็ต + ใช้ system python3 (venv ไม่มี PIL)
