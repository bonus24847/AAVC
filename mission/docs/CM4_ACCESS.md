# CM4 บนโดรน — ที่อยู่ / บัญชี / กุญแจ

รวบรวมจากร่องรอยในเครื่องโน้ตบุ๊ก 2026-08-15 (ผู้ใช้ถาม: "ไม่รู้ว่าที่อยู่ CM4
คืออะไร") — ค่าพวกนี้ถูกเดินสายเข้าสคริปต์ทุกตัวแล้ว ไม่ต้องจำเอง

| ของ | ค่า | มาจากไหน |
|---|---|---|
| ผู้ใช้ | **`drone`** | ค่าที่ AAVC GCS ใช้ (`CM4_USER`) + ประวัติ ssh เดิม |
| ที่อยู่ | **`<วง WiFi ปัจจุบัน>.41`** | CM4 จองเลขท้าย **.41** เสมอ (เคยใช้ `drone@192.168.14.41` ตอนต่อ hotspot) |
| กุญแจ ssh | **`~/.ssh/cm4_key`** (ชื่อไม่มาตรฐาน!) | มีคู่ `.pub` ระบุ `laptop-to-cm4` |
| โฟลเดอร์ mission | `~/mission` (ตั้งโดย `cm4/deploy.sh`) | — |

⚠ **กุญแจชื่อไม่มาตรฐาน = ต้องระบุเสมอ**: `ssh drone@…` เฉย ๆ จะเด้งถามรหัสผ่าน
เพราะ ssh ไม่รู้จักไฟล์ชื่อ `cm4_key` ทุกสคริปต์ในโปรเจกต์นี้ (`deploy.sh`,
`launch_gcs_real.sh`, `status_sync.sh`, ไอคอนเครื่องจริง) จึงใส่ `-i` ให้เอง
ถ้าจะ ssh มือ ต้องพิมพ์เองว่า:

```bash
ssh -i ~/.ssh/cm4_key drone@<ip>
```

## เลิกพึ่ง hotspot มือถือ (ผู้ใช้ 2026-08-16)

hotspot จากมือถือของผู้ใช้เป็นทางที่ใช้ตอน**พัฒนา**เท่านั้น (ตั้งไว้ให้ Claude
เข้าไปดู/แก้ของบน CM4 ได้) **วันแข่งไม่ควรพึ่ง** — มือถือสายเข้า แบตหมด หรือเดินออก
นอกระยะ = คุมทั้งระบบไม่ได้ มี 3 ทางแทน เรียงตามที่แนะนำ:

| | ต้องมีอะไร | ใช้ตอนบินได้ | เหมาะกับ |
|---|---|---|---|
| **① CM4 ปล่อย WiFi เอง** | ไม่ต้องมีอะไรเพิ่ม | ✅ | **ค่าเริ่มต้นวันแข่ง** |
| ② สาย LAN ตรง | สาย + พอร์ต RJ45 บนบอร์ด | ❌ (ต่ออยู่กับที่) | พิท / พื้นที่พัก (ห้ามส่งคลื่น) |
| ③ USB gadget | บอร์ดมีพอร์ต USB-C OTG | ❌ | สำรองถ้าไม่มี RJ45 |

**⚠ สาย FC ไม่ใช่คำตอบ** — สายจากโน้ตบุ๊กไป Pixhawk ให้ MAVLink กับ **ตัวคุมการบิน**
(ใช้สั่ง servo / QGC ได้) แต่ **ไปไม่ถึง CM4** ซึ่งเป็นคอมพิวเตอร์คนละตัว
โปรแกรมภารกิจอยู่บน CM4 ⇒ การกดปุ่ม 🚀 ต้องมีเส้นทาง **IP** ถึง CM4 เสมอ

### ① CM4 ปล่อย WiFi เอง — แนะนำ

กลับด้านจากเดิม: **โดรนเป็นคนปล่อยสัญญาณ โน้ตบุ๊กเข้าไปหา** ไม่ต้องมีมือถือ ไม่ต้อง
มีเราเตอร์ ไม่ต้องมีอินเทอร์เน็ต และเป็นลิงก์ท้องถิ่นในย่านที่กติกาแนะนำอยู่แล้ว
(2400–2500 / 5725–5850 MHz — ที่ห้ามคือ 4G/ซิม)

```bash
ssh -i ~/.ssh/cm4_key drone@<ip ปัจจุบัน>
bash ~/mission/cm4/setup_ap.sh              # ดูก่อนว่าจะทำอะไร
bash ~/mission/cm4/setup_ap.sh --apply      # ทำจริง (ถามรหัส sudo)
```

จากนั้นที่โน้ตบุ๊ก: เข้าวง **AAVC-DRONE** → `bash cm4/launch_gcs_real.sh drone@10.42.0.1`

⚠ ที่อยู่เปลี่ยนเป็น **10.42.0.1** (CM4 เป็นเจ้าของวงเอง ไม่ใช่ `.41` แบบเดิม) —
`cm4/find_cm4.sh` หาเจออยู่แล้วเพราะมันกวาดทั้งวง ไม่ได้ยึดเลขท้าย
⚠ AP = CM4 กำลังส่งคลื่น **กติกาห้ามส่งขณะอยู่ในพื้นที่พัก** ⇒ ในพิทใช้สาย LAN
แล้วเปิด AP ตอนถึงไลน์บิน (`sudo nmcli connection up AAVC-AP` / `down` เพื่อปิด)

### ② สาย LAN ตรงโน้ตบุ๊ก ↔ CM4

ไม่มีคลื่นเลย เหมาะกับพื้นที่พักที่ห้ามส่งสัญญาณ ตั้งเลขนิ่ง ๆ ทั้งสองฝั่ง:

```bash
# บน CM4 (ครั้งเดียว)
sudo nmcli connection add type ethernet ifname eth0 con-name aavc-lan \
     ipv4.method manual ipv4.addresses 192.168.77.41/24 autoconnect yes
# บนโน้ตบุ๊ก (แทน <eth> ด้วยชื่อการ์ด เช่น enp0s31f6 — ดูด้วย: ip -br link)
sudo nmcli connection add type ethernet ifname <eth> con-name aavc-lan \
     ipv4.method manual ipv4.addresses 192.168.77.10/24 autoconnect yes
```

แล้ว `bash cm4/launch_gcs_real.sh drone@192.168.77.41` ได้เลย

**ลำดับที่ใช้จริงวันแข่ง:** เสียบสายในพิท → ตั้ง id 4 ตัว + สั่ง stage → ถอดสาย →
นักบินยก RC ปล่อย (mission ทำงานเองบน CM4 ไม่ต้องมีลิงก์)

## หา ip ของ CM4 ยังไง

1. **ไอคอน "AAVC GCS เครื่องจริง" หาให้เอง** — มันสแกนวง WiFi ปัจจุบันหาเครื่องที่
   ลงท้าย .41 ที่เปิดพอร์ต ssh แล้วเติมช่องให้ (ถ้าเจอจะขึ้น "พบ CM4 ในวงนี้แล้ว ✔")
2. หามือ: `ip -4 addr` ดูวงของโน้ตบุ๊ก (เช่น `192.168.2.39/24`) → CM4 คือ
   `192.168.2.41` → ลอง `ssh -i ~/.ssh/cm4_key drone@192.168.2.41 hostname`
3. ถ้ายังไม่เจอ: CM4 ยังไม่บูตเสร็จ / ยังไม่เข้าวง WiFi นี้ (ครั้งแรกบนวงใหม่ต้อง
   ตั้ง WiFi ให้มันก่อน — จอ+คีย์บอร์ด หรือแก้ไฟล์ใน SD card)

## ต้องกรอกอะไรบ้างตอนใช้ AAVC GCS เครื่องจริง

ช่องเดียว: **`drone@<ip>`** (เช่น `drone@192.168.2.41`) — ที่เหลือสคริปต์จัดการเอง
(กุญแจ, พอร์ต telemetry 14550, คำสั่งปุ่ม 🚀, status_sync, แผนที่สนาม)
ค่าที่กรอกจะถูกจำไว้ที่ `~/.config/aavc/cm4_host` ครั้งหน้ากด Enter ผ่านได้เลย
